# ==== 导入钱包扩展数据步骤 ====
1️⃣关闭浏览器
2️⃣进入浏览器的扩展目录（见下⬇️） 
3️⃣将钱包扩展数据复制到其对应的ID文件夹下
4️⃣打开浏览器，使用密码登录钱包

## windows 浏览器扩展目录示例
## 默认用户为 Ddfault ，其它用户为 Profile 1、Profile 2 ......

- **chrome Dev**
%LOCALAPPDATA%\Google\Chrome Dev\User Data\Profile 5\Local Extension Settings
- **chrome canary**
%LOCALAPPDATA%\Google\Chrome SxS\User Data\Profile 3\Local Extension Settings
- **Edge**

- **Brave**
